# The fifth-order Arkon recurrence (A006343)

The specified Mathar recurrence is formally proved for every index `m >= 5`,
starting from the independently defined generating function. The project
also proves existence and uniqueness for its Catalan inverse specification.

See the [Lean proof and full statement](lean/README.md),
[main theorem](lean/MathLean/Arkon.lean), and
[verification record](lean/VERIFICATION.md).

This problem is delivered directly as a Lean project. It has no separate
PDF paper. The recurrence and original generating function are attributed
to [OEIS A006343](https://oeis.org/A006343), including Mathar's 2020 formula.
No novelty or external peer-review claim is made.
